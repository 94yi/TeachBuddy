# 微信公众号教学资源目录

资源库是所有已登录访客共享的文章目录，使用现有数据目录下的 `resources.sqlite3` 持久化；现有文件知识库仍按浏览器会话隔离。清除浏览器会话不会清除共享资源目录。

## 使用

在资源库粘贴一篇公开微信公众号文章的完整 HTTPS 链接，可选填学科和年级。支持 `https://mp.weixin.qq.com/s/短链接` 和包含 `__biz`、`mid`、`idx`、`sn` 的长链接。

每次导入只保存标题、公众号名称、页面提供的短摘要、原文链接、发布日期（页面有可直接读取的日期时）及采集时间。缺失的字段留空；不根据正文猜摘要，不保存正文、图片或附件，也不会访问文章中的其他链接。相同规范链接再次导入会更新同一条记录。

导入的短链接如跳转到完整文章链接，以最终链接去重。如果同一篇文章有两个均不跳转的不同短链接，无法仅凭元数据确认是同一篇，仍可能形成两条记录。

点击“加入我的资料”会把目录信息及来源链接复制到当前浏览器的私有知识库，供备课时选择；它不包含文章全文。删除共享目录记录不会删除此前已复制到私人知识库的记录。共享密码的持有人都可以导入和删除目录记录，当前版本没有区分管理员角色。

## 访问与运行边界

- 每次导入一篇，整个服务最多同时读取一篇；单会话每分钟最多 5 次，全服务每分钟最多 10 次。
- 总网络时限为 20 秒，页面最大 2 MB，最多 2 次跳转。只接收未压缩的 HTML；服务不使用环境代理、浏览器 Cookie 或公众号登录凭据。
- 仅允许 `mp.weixin.qq.com` 的 HTTPS 文章路径和 443 端口。每次跳转重新校验 URL 与 DNS；所有 DNS 答案必须为公网地址，TLS 连接固定到已验证 IP，并正常校验 `mp.weixin.qq.com` 证书和 SNI。
- 验证码、登录提示、被删除或不支持的页面会显示失败，不绕过验证，也不会把错误页保存成成功资源。
- 当前不提供按公众号名称获取全部历史、定时采集、正文/附件下载或公众号官方管理 API 集成。首次真实采集需使用明确的公开文章链接；部署不会自带或自动采集真实文章。

## API

所有 API 沿用登录及 `X-TeachBuddy-Request: 1` 写请求校验。

- `GET /api/resources?q=&subject=&grade=&page=1&page_size=12`：关键词（标题、摘要、公众号）及学科年级过滤；返回 `items,total,page,page_size,pages`。
- `POST /api/resources/import`：JSON `{ "url": "...", "subject": "", "grade": "" }`，成功返回 `{ "item": {...}, "created": true }`。
- `DELETE /api/resources/{id}`：删除共享资源。
- `POST /api/resources/{id}/knowledge`：复制资源目录信息到当前会话知识库。

每条记录包含 `id,title,summary,account,source_url,subject,grade,published_at,fetched_at,created_at,updated_at`。目录上限 5000 条，分页最大 50 条；数据库和 WAL 文件计入已有全局存储额度。SQLite 在已有可写数据卷内初始化，兼容容器只读根目录和非 root 用户，无新增依赖。

## 备份与验证

沿用完整数据卷备份。数据库可能存在 WAL 文件：备份时停止应用容器再备份整个数据目录，或使用 SQLite 的在线备份 API；运行中不要只复制 `resources.sqlite3` 主文件。

`tests/test_resources.py` 使用真实临时 SQLite，外部网络全部模拟，覆盖解析、去重、重启读取、中文查询、分页、URL/DNS/跳转/超时/大小、登录校验和私有知识库隔离。模拟测试不等于已成功采集某个实际公众号；真实文章会受微信侧访问策略影响。
`tests/resource_browser_smoke.py` 在隔离进程中替换微信网络响应，使用真实 SQLite 与网页验证导入、去重、中文筛选、分页、加入私有资料、失败提示和手机布局。所有文章均为合成测试数据，不会发送到生产站点。
